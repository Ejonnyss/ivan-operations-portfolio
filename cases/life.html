02 / PRODUCT DEVELOPMENT

LIFE: REBUILD

A life navigation product that keeps action and real-world outcome separate.

Context and problem

The product maps meaningful life areas, one current route and limited alternatives. It is designed to show a path through life decisions, rather than turn life into a points-based task list. The public beta already had routes, mission scenes, local persistence, encrypted private plans and an offline shell. A new visitor could not enter the experience without a private plan file.

Options and decision

Releasing personal goals or recordings was excluded. Adding accounts and a remote database would solve a different problem and add cost. I chose an isolated fictional route that demonstrates the central loop while keeping private data separate.

Implementation

The demo contains three fictional spheres and short routes. A visitor simulates an invitation, then separately simulates a participant's reply. The first action never marks the external result complete. The demo selects its own IndexedDB database before reading state or media; it never imports a personal encrypted pack.

What I directed and what AI did

  • Owner direction: the life navigation model and the requirement for a safe, working portfolio demo.
  • Product decision: a bounded synthetic entry route instead of exposing a private plan.
  • AI/Codex implementation: demo pack, storage isolation, labels, README and regression test.
  • Verification: clean install, 39/39 automated tests, lint, build, local browser flow, mobile and desktop visual checks, Pages deployment readback.
  • Owner acceptance: not yet recorded; physical iPhone behavior and long-term usefulness are open.

Result and learning

The public link lets a reviewer enter, complete the action/outcome sequence and return to saved demo state after a reload. A fresh install now saves the shell and illustrations without waiting for all 16 videos; the user can save the videos separately for offline viewing. Browser QA confirmed an offline reload from the live link at 390 px, while physical-iPhone acceptance remains open. The evidence establishes a working product loop; there are no measured retention, employment or revenue results.
